# rivera (Ririkan)

Developer-oriented multi-app release state monitoring dashboard for iOS and Android.

## Features

- **Multi-app Management**: Monitor App Store Connect and Google Play Console status in one dashboard
- **Real-time State Monitoring**: Review status, build failures, and crash summaries
- **PDF/CSV Export**: Generate detailed reports for app reviews and releases
- **Home Screen Widget** (Android): Quick access to app attention status
- **Submission Checklist**: Pre-release verification checklist
- **Revenue Summary**: Track DL count and revenue trends

## Architecture

- **Flutter 3.x** with Dart 3.12.2
- **Riverpod 2.6.1** for state management
- **go_router 14.8.1** for navigation
- **flutter_secure_storage** for API key protection
- **Material Design 3** dark theme
